## 1. [microsoft/skills](https://github.com/microsoft/skills) — 3k звёзд

Репозиторий от Microsoft: 175 скиллов, кастомные агенты, MCP‑конфигурации и шаблон `AGENTS.md` для Azure SDK и AI Foundry.

```
microsoft/skills/
├── AGENTS.md                          # Шаблон конфигурации поведения агента
├── context7.json                      # Конфиг MCP-сервера
├── .claude/                           # Настройки Claude Code
├── .claude-plugin/                    # Манифест плагина Claude
├── .opencode/                         # Конфиг для OpenCode
├── .github/
│   ├── copilot-instructions.md        # Инструкции для GitHub Copilot
│   ├── skills/                        # SKILL.md-файлы (по одному на домен)
│   │   └── <skill-name>/
│   │       └── SKILL.md
│   ├── plugins/                       # Бандлы по языкам (azure-sdk-python и т.д.)
│   │   └── azure-sdk-*/
│   │       ├── skills/
│   │       ├── commands/
│   │       └── agents/
│   ├── prompts/                       # Переиспользуемые промпт-шаблоны
│   │   ├── code-review.prompt.md
│   │   ├── create-store.prompt.md
│   │   └── add-endpoint.prompt.md
│   ├── agents/                        # Персоны агентов
│   │   ├── backend.agent.md
│   │   ├── frontend.agent.md
│   │   ├── infrastructure.agent.md
│   │   └── planner.agent.md
│   ├── scripts/                       # Автоматизация (скрапинг доков)
│   └── workflows/                      # GitHub Actions (ежедневное обновление)
├── skills/                            # Симлинки для обратной совместимости
│   ├── python/   → ../.github/skills/*-py
│   ├── dotnet/   → ../.github/skills/*-dotnet
│   ├── typescript/ → ../.github/skills/*-ts
│   ├── java/     → ../.github/skills/*-java
│   └── rust/     → ../.github/skills/*-rust
├── tests/                              # Тест-харнес для валидации скиллов
└── hooks/continual-learning/           # Хуки для дообучения агента
```

Ключевое: каждый скилл — папка с `SKILL.md` (YAML frontmatter + Markdown‑тело), агенты — отдельные `.agent.md`, промпты — `.prompt.md`. [```6```](https://github.com/microsoft/skills)

## 2. [rpmcginty/ai-config](https://github.com/rpmcginty/ai-config) — портативная конфигурация

Идея: один репозиторий для всех AI‑конфигов, синхронизируется через симлинки в `~/.claude/skills/` и `~/.agents/skills/`.

```
ai-config/
├── AGENTS.md                           # Базовые правила агента
├── README.md
├── bin/
│   └── sync                            # Единственный скрипт: симлинки + проверка дрейфа
├── instructions/                       # Глобальные инструкции (линкуются в $HOME)
│   ├── AGENTS.md                       # Правила поведения агента
│   ├── VOICE.md                        # Стиль письма
│   └── OPINIONS.md                     # Инженерные предпочтения
├── skills/                             # Иерархическое дерево скиллов
│   └── <domain>/
│       └── <skill-name>/
│           └── SKILL.md               # Фронтматтер + тело, lifecycle через status: draft/stable
├── skills/meta/                        # Скиллы для обслуживания самого репо
│   ├── new-skill/                     # Генератор шаблона нового скилла
│   └── audit-skills/                  # Аудитор: проверяет дрейф и пересечения
└── docs/                               # Конвенции, структура, механика синхронизации
```

Ключевое: `bin/sync` раскладывает всё по нужным путям через симлинки. Приватные оверлеи — отдельные репо с той же структурой `skills/` + `instructions/`, накладываются поверх. [```7```](https://github.com/rpmcginty/ai-config)

## 3. [lifedever/claude-rules](https://github.com/lifedever/claude-rules) — стандарты кодирования для AI

Библиотека правил в三层 архитектуре: base → language → framework. Конкатенируешь нужные файлы и кладёшь туда, где их ждёт твой инструмент.

```
claude-rules/
├── base/                               # Универсальные правила (обязательный слой)
│   ├── core.md                         # Принципы, нейминг, архитектура
│   └── git.md                          # Конвенции коммит-сообщений
├── languages/                          # Правила по языкам (выбрать один)
│   ├── typescript.md                   # Запрет any/enum, as const, import type
│   ├── javascript.md                   # ES2022+, ESM only
│   ├── python.md                       # ruff, type annotations, Protocol
│   ├── go.md                           # Error wrapping, малые интерфейсы
│   ├── rust.md                         # Ownership, thiserror/anyhow
│   ├── java.md                         # Java 17+ record/sealed
│   └── ...
└── frameworks/                         # Правила по фреймворкам (выбрать один)
    ├── vue.md                          # script setup, ref vs reactive, composables
    ├── react.md                        # Hooks, useEffect, state layering
    ├── springboot.md                   # Слои, DTO, глобальный exception handling
    └── tauri.md                        # Commands, service encapsulation
```

Ключевое: правила — обычный Markdown. Вывод кладётся в `CLAUDE.md`, `.cursor/rules/*.mdc` или `.github/copilot-instructions.md` в зависимости от инструмента. Приоритет: framework > language > base. [```1```](https://github.com/lifedever/claude-rules)

Каталог паттернов AI‑разработки с конкретной структурой конфигурации агентов.

```
├── .codex/                             # Конфиг OpenAI Codex
├── .agents/
│   └── skills/
│       └── evaluate-pattern-adoption/   # Скилл оценки внедрения паттернов
│           └── SKILL.md
├── .github/
│   └── ...                             # Actions, CI/CD
├── examples/                           # Полные примеры паттернов
│   ├── codified-rules/
│   ├── developer-lifecycle/
│   ├── guided-refactoring/
│   └── ...

├── scripts/                            # Автоматизация

```

Ключевое: трёхуровневая архитектура правил. Основной файл — роутер (<60 строк), специализированные правила подгружаются по demand: [```21```](https://github.com/PaulDuvall/ai-development-patterns)

## 5. [Consensys docs-template](https://docs-template.consensys.io/create/repo-structure) — шаблон документации с AI‑конфигом

Готовый шаблон для Docusaurus с встроенной конфигурацией AI‑агентов.

```
docs-site/
├── AGENTS.md                           # Root-контекст для всех AI-агентов
├── .cursor/
│   ├── rules/                          # Правила Cursor (MDC-формат)
│   │   ├── content-types.mdc            # Правила по типам контента (Diataxis)
│   │   ├── contributor-workflow.mdc      # Workflow контрибьюторов
│   │   ├── editorial-voice.mdc           # Эдиторный голос/стиль
│   │   ├── markdown-formatting.mdc        # Форматирование Markdown
│   │   └── terminology.mdc                # Терминология проекта
│   └── skills/                          # Скиллы Cursor (SKILL.md)
│       ├── author-page/
│       │   └── SKILL.md
│       └── style-review/
│           └── SKILL.md
├── .github/
│   ├── copilot-instructions.md          # Инструкции для Copilot
│   └── ...                              # Actions, issue templates
└── ...                                  # Сам сайт (docs/, static/, docusaurus.config.js)
```

Ключевое: `.cursor/rules/*.mdc` с frontmatter-метаданными (description, globs, alwaysApply), скиллы — отдельные `SKILL.md` в подпапках. `AGENTS.md` служит точкой входа для любого AI‑агента. [```20```](https://docs-template.consensys.io/create/repo-structure)

## Сводка: что где лежит

| Инструмент | Файл / папка | Формат |
|---|---|---|
| **Claude Code** | `CLAUDE.md` в корне + `~/.claude/skills/` | Markdown |
| **Cursor** | `.cursor/rules/*.mdc` | MDC (Markdown + frontmatter) |
| **GitHub Copilot** | `.github/copilot-instructions.md` + `.github/instructions/*.instructions.md` | Markdown + YAML frontmatter |
| **Универсальный** | `AGENTS.md` в корне (поддержка: Codex, Cursor, Claude, Gemini) | Markdown |
| **Скиллы** | `.github/skills/<name>/SKILL.md` или `.claude/skills/<name>/SKILL.md` | YAML frontmatter + Markdown |
