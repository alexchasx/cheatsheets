
# Разные хитрости при работе с ИИ

- промты на английском экономят токены, поэтому, используя русский язык, переводи его в английский

- после 40% контекста начинается "тупая зона" (ИИ туипит), поэтому контекст лучше скинуть

- вместо разделения на работу с View, Controller, Model лучше делать отдельный функционал,  который включает в себя View, Controller, Model, и давать доступ ко всему коду, а не к отдельному слою

- LLM читает файл по 200 символов, а дальше на основе прочитанного определяет нужно ли читать дальше
(первые 200 символов имеют большое значение)

- tessl.io - библиотека Skills для ИИ
```bash
npx tessl init
npx tessl search qa-test-planer     # поиск в реестре
```
