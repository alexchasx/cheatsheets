
## PHP - `Hypertext Preprocessor` (Препроцессор Гипертекста). 
Первоначально: `Personal Home Page`. Создан на основе языка Perl.

## Краткая история
Первый релиз от Rasmus Lerdorf в 1995 году.
PHP 3 - 1998 г.
PHP 4 - 2000 г.
PHP 5 - 2004 г.
PHP 6 - в 2010 признана бесперспективной из-за сложностей с поддержкой Юникода
PHP 7 - 2015 г.
PHP 8 - 2020 г.

- `php 5.0`:   
    рывок в ООП. Производительность почти не изменилась.
- `php 5.1 и 5.2`:   
    магические методы __isset и __unset. включение PDO по умолчанию и др.
- `php 5.3`:   
    неймспейсы, лямбды и замыкания, сокращенный тернарный оператор `?:` и др.
- `php 5.4`:   
    traits, короткая запись массивов `[]` и др.
- `php 5.5`:  
    генераторы, ключевое слово "finally" и др.
- `php 5.6`:  
    переменное кол-во аргум-в `(...$params)` и развертывание аргументов c помощью оператора `...`
- `php 7`:  
    работает быстрее в 2-3 раза, скалярные тайпхинты, операторы: объединения с null `??` и spaceship `<=>`, анонимные классы и др.

## Особенности
- Интерпретеруемый (Операторы выполн-ся друг за другом с помощью программы-интерпретатора. Скрипт создается во время обращения к нему).
- Ядро - Zend Engine.
- Код может внедряться непосредственно в HTML.
- Файлы имеют расширение `.php`.
- Код начинается с тега `<?php` (Закрывать тег не рекомендуется, если далее нет HTML)

Пример (файл `index.php`):
```php 
<?php
echo "Привет!";
```

Три основные области применения:

1) Скрипты для серверов. Генерация веб-страниц.
2) Консольные скрипты.
3) Оконные приложения на стороне клиента (не самый лучший язык для такого).

Доступно формирование изображений, файлов PDF, XML-файлов, роликов Flash.
Поддержка широкого круга баз данных.
PHP может обмениваться структурами данных между другими языками веб-программирования.

## Первый запуск в Windows.
Из командной строки можно выполнить без внесения каких-либо изменений:

```bash
C:\php\php.exe -f "C:\PHP Scripts\script.php" -- -arg1 -arg2 -arg3
```

Чтобы запускать PHP из любого каталога нужно выполнить несколько шагов: 
- добавить путь файла `php.exe` в переменную окружения PATH, 
- связать расширение .PHP с типом файла 
- и др. (см. документацию).

Эти же изменения можно сделать в реестре в ручную (см. документацию).

Есть проблемы PHP под Windows:
- проверка прав на временную директорию (см. документацию).

## PHP-FPM (или FastCGI Process Manager)

Интерпретатор PHP может быть интегрирован в веб-сервер в виде специального модуля `mod_php` или использоваться как отдельный сервис `php-fpm` (более гибок в настройке, чем `mod_php`).

Три режима управления процессами:

1) `static` - фиксирует количество дочерних процессов (подойдет сайту с высоким трафиком);

2) `dynamic` - динамически регулирует количество дочерних процессов (не менее одного);

3) `ondemand` - форкает процессы при получении запросов (подойдет сайту с низким трафиком).

Обслуживайте фронтенд и бэкенд вашего сайта, используя разные пулы (обработчики, группы процессов).

Есть общий конфигурационный файл `/etc/php/7.4/fpm/php-fpm.conf` и конфигурационный файл для каждого обработчика в каталоге `/etc/php/7.4/fpm/pool.d/`.
