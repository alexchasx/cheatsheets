
# Терминология в программировании простым языком.

## Структуры данных

`Односвязный список (singly linked list)` - список узлов, связанных в одном направлении. Каждый узел имеет значение и указатель на следующий (или предыдущий) узел.

`Двусвязный список (Doubly linked list)` - список узлов, связанных в обоих направлениях. Каждый узел имеет значение и указатели на следующий и предыдущий узлы.

`Куча (Heap)` - древовидная струтура, каждый узел которой больше или равен своим потомкам.

`Стэк (Stack)` - список элементов, организованный по принципу "первый пришёл - последний ушёл".

`Очередь (Queue)` - список элементов, организованный по принципу "первый пришёл - первый ушёл".

`Массив (Array)` - структура данных, которая хранят данные в непрерывном виде, доступные через индексы.

`Хеш-таблица` — это структура данных, реализующая интерфейс ассоциативного массива, т.е. позволяет хранить пары (ключ, значение) и выполнять три операции: добавления, удаления и поиска.

`Карта (Map)` - это структура данных, содержащая пары ключ-значение.

`Перегрузка в PHP` означает возможность динамически создавать свойства и методы.
Традиционно `перегрузка` означает возможность иметь несколько одноимённых методов с разным параметрами.

## Базы данных

`Реляционная база данных` – база данных, основанная на реляционной модели (Данные представляются в виде отношений).

`Транзакция` - совокупность SQL-запросов, которые либо будут все успешно выполнены, либо не будет выполнен ни один из них.

`Кортеж` - множество пар "Атрибут – Значение" (строки таблиц).

`Домен атрибута` — множество допустимых значений, которые может принимать атрибут.

`Аномалией` называется такая ситуация в таблице БД, которая приводит к противоречию в БД либо существенно усложняет обработку данных.

`Первичный ключ` однозначно идентифицирует записис таблицы (может быть составным).

`Нормализация БД` - организация данных в БД по требованиям "Нормальных форм".

`Первая нормальная форма (1NF)`: ячейки таблицы должны иметь атомарные значения; строки не должны дублироваться.

`Вторая нормальная форма (2NF)`: данные должны зависеть от первичного ключа (если ключ составной - то от всего ключа в целом).

`Третья нормальная форма (3NF)`: нужно выносить данные в отдельные таблицы, если они зависят не только от первичного ключа.

`Денормализация` – процесс обратный нормализации. Часто применяется для ускорения процесса чтения данных из базы данных.

`Транзитивная зависимость` – смысловая зависимость одного атрибута от другого при условии, что ни один из них не является первичным ключом.

`Репликация` — это процесс копирования данных из одного источника на другой.

## Многопоточность

`UI` - пользовательский интерфейс.

`Процесс` — программа, которая выполняется в текущий момент.

`Thread` - поток выполнения («малая» единица обработки, находящаяся внутри процесса). Потоки выполнения легче процессов.

`Worker` - отдельный контекст для выполнения фоновых задач (используется для выполнения подзадач внутри потока).

`Pool` - это контейнер для повторно используемых ресурсов (используется для создания группы воркеров).
