
# Шаблон проектирования Фасад в PHP

Тип: структурный.

Назначение: предоставляет единый интерфейс к группе интерфейсов

Реализация:
- через конструтор внедрить в Фасад объекты подсистем,
- реализовать методы в Фасаде, работающие с данными объектами.

Хороший фасад не содержит созданий экземпляров классов (new) внутри.

Похож на Декоратор: только в Фасад внедряется несколько объектов.
