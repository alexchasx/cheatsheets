
# Порождающие

## Абстрактная фабрика
Создаёт группы связанных объектов, не указывая их конкретные классы.

## Builder (Строитель)
Разделяет создание объекта от его представления.

## Фабричный метод 
Делегирует создание объектов подклассам.

##  Прототип
Копирует объекты по определенному прототипу.

## Singleton (Одиночка)
Гарантирует, что у класса будет только один экземпляр.


---
# Структурные

##  Адаптер
Преобразуйте интерфейс класса в другой интерфейс. 

##  Мост
Отделяет абстракцию от реализации.

##  Композит (Компоновщик)
Одинаково работает с составными и отдельными объектами.

##  Декоратор
Расширяет функциональность без наследования.

##  Фасад
Единый интерфейс для группы интерфейсов.

##  Прокси
Замена другого объекта для контроля доступа к нему.

---
# Поведенческие

##  Команда
Инкапсулирует запрос в виде объектов, позволяя передавать их клиентам в качестве параметров, ставить в очередь, логировать, а также поддерживает отмену операций.
Инкапсуляция вызовов методов.

##  Итератор
Позволяет перемещаться по элементам некоторой последовательности.

##  Посредник
Разделяет взаимодействия между объектами.

##  Наблюдатель
Определяет отношение «один-ко-многим» между объектами. Когда состояние одного объекта изменяется, все зависимые объекты получают оповещения.

##  Состояние
Позволяют объекту изменять свое поведение при изменении его внутреннего состояния.

##  Стратегия
Определяет группу алгоритмов, инкапсулирует их и делает взаимозаменяемыми.

##  Метод шаблонов
Позволяюет подклассам переопределять шаги алгоритма, не изменяя алгоритм в целом.
