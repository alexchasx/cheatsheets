

## Создание дампа базы
```bash
# входим в контейнер БД и вводим
PGPASSWORD=postgres pg_dump --username postgres db_name > dump.sql
# выходим из контейнера и вводим
docker cp db:/dump.sql /home/alex/_elcom/dump.sql

```


## Обновить БД
```bash
# - остановить докер-кон-ы
# - заменяем 'dump.sql.gz' на новый дамп в '/portal/tmp/db/'
# - запустить контейнеры 
# db_name - имя БД
psql  -U postgres -c 'DROP DATABASE IF EXISTS db_name WITH (FORCE);'
psql  -U postgres -c 'CREATE DATABASE db_name;'
zcat /var/lib/postgresql/data/pgdata/dump.sql.gz | psql -U postgres -d db_name

```
