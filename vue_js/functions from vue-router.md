Вот краткое описание указанных функций и утилит из `vue-router@4`:

---

- **`createMemoryHistory`** — создаёт историю навигации в памяти (без изменения URL в браузере). Полезно для тестов, SSR или кастомных сценариев, где адресная строка не должна меняться.
- **`createRouter`** — главная функция для создания экземпляра роутера. Принимает конфигурацию (`history`, `routes` и др.) и возвращает объект роутера, который подключают через `app.use(router)`.
- **`createRouterMatcher`** — низкоуровневая утилита для создания матчера маршрутов (сопоставляет пути с описаниями маршрутов). В основном используется внутри роутера, редко вручную.
- **`createWebHashHistory`** — создаёт историю на основе хеша в URL (`#`). Подходит для простых хостингов без настройки сервера; URL выглядят как `example.com/#/home`.
- **`createWebHistory`** — создаёт «обычную» историю без хеша (режим HTML5 History). Даёт чистые URL (`/home`), но требует настройки сервера (редирект на `index.html` при 404).
- **`isNavigationFailure`** — утилита для проверки, является ли переданный объект ошибкой навигации (например, из-за отмены в guard). Позволяет отличить «нормальную» ошибку от «отмены перехода».
- **`loadRouteLocation`** — внутренняя/продвинутая утилита: загружает данные маршрута по объекту локации. Чаще используется внутри роутера; в обычном коде не нужна.
- **`onBeforeRouteLeave`** и **`onBeforeRouteUpdate`** — хуки для отслеживания ухода с маршрута и обновления маршрута внутри компонента. В Composition API используются через подписку на события роутера либо логику в guards; в чистом `<script setup>` их нет как макросов.
- **`parseQuery`** — парсит строку query-параметров (например, `?page=2&sort=asc`) в объект (`{ page: '2', sort: 'asc' }`).
- **`stringifyQuery`** — обратная операция: превращает объект query-параметров в строку (например, `{ page: 2 }` → `?page=2`).
- **`useLink`** — внутренний API для реализации `<router-link>`. Не предназначен для прямого использования в компонентах.
- **`useRoute`** — Composition API-хук, возвращает реактивный объект текущего маршрута (`path`, `params`, `query`, `meta` и т. д.).
- **`useRouter`** — Composition API-хук, возвращает экземпляр роутера для программной навигации (`push`, `replace`, `back` и т. п.) и доступа к истории.
